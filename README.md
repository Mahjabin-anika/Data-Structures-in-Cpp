# Data Structures in C++

This repository contains my academic work for the Data Structures course. It includes C++ programs that I practiced and completed during the course.

## Topics Covered

* Basic C++ practice
* Arrays
* Searching
* Sorting
* Stack
* Queue
* Linked List

The programs include different implementations of searching and sorting algorithms, array operations, stack and queue operations, and linked list operations.

## Folder Structure

* **Learn Basic C++** – Basic C++ practice programs
* **Arrays** – Array-related programs
* **Searching** – Linear and Binary Search
* **Sorting** – Bubble, Selection, Insertion, and Merge Sort
* **Stack** – Stack implementations
* **Queue** – Queue and Circular Queue
* **Linked List** – Singly, Circular Singly, and Doubly Linked List programs
